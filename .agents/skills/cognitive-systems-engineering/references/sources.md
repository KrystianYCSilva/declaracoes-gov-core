|--------|-------------|---------------|

| [Evaluating Human-AI Collaboration: A Review and Methodological Framework (2024)](https://arxiv.org/abs/2407.19098) | Structured decision tree for selecting collaboration metrics; distinguishes AI-centric, human-centric, and symbiotic modes | 2025-07-01 |
| [Human-AI Collaboration by Design (Cambridge, 2024)](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/45BC30ADFF2FE3B204D4A29DD67F6353/S2732527X2400227Xa.pdf/human-ai-collaboration-by-design.pdf) | Mixed-initiative and co-creation models with explainable AI; useful for preserving human agency in engineered systems | 2025-07-01 |
| [Cognitive DevOps: A Framework for Human-AI Collaboration (WJARR, 2025)](https://wjarr.com/sites/default/files/fulltext_pdf/WJARR-2025-1969.pdf) | Proposes multi-agent AI with human supervision, real-time collaborative triage, and adaptive trust calibration | 2025-07-01 |
| [A Cognitive Approach to Human-AI Complementarity (Nature, 2025)](https://www.nature.com/articles/s44159-025-00499-x) | Frames cognitive complementarity: AI for data/pattern recognition, humans for context awareness and ethical reasoning | 2025-07-01 |

| [ReAct: Synergizing Reasoning and Acting (Yao et al., 2022)](https://arxiv.org/abs/2210.03629) | Key reference for OODA-like observe-orient-decide-act engineering cycle in language agents | 2025-07-01 |
