# Cognitive Architectures — Sources

| Source | Description | Last verified |
|--------|-------------|---------------|
| [CoALA: Cognitive Architectures for Language Agents (Sumers et al., 2024)](https://arxiv.org/abs/2309.02427) | Primary survey bridging SOAR, ACT-R, and modern LLM agents; defines modular vocabulary for memory, action space, and decision loops | 2025-07-01 |
| [Awesome Language Agents — GitHub (ysymyth)](https://github.com/ysymyth/awesome-language-agents) | Curated bibliography of 300+ works maintained by CoALA authors; continuously updated with papers, benchmarks, and tools | 2025-07-01 |
| [ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)](https://arxiv.org/abs/2210.03629) | Defines the Reason+Act loop; key reference for interleaved reasoning and tool-use patterns in decision loops | 2025-07-01 |
| [Generative Agents: Interactive Simulacra of Human Behavior (Park et al., 2023)](https://arxiv.org/abs/2304.03442) | Episodic memory, reflection, and social simulation patterns; useful for continuity-focused architectures | 2025-07-01 |
| [Chain-of-Thought Prompting Elicits Reasoning in LLMs (Wei et al., 2022)](https://arxiv.org/abs/2201.11903) | Demonstrates explicit reasoning steps; foundational for understanding decision loop design | 2025-07-01 |
| [Tree of Thoughts: Deliberate Problem Solving (Yao et al., 2023)](https://arxiv.org/abs/2305.10601) | Extends CoT to multi-path exploration; useful when evaluating richer decision patterns | 2025-07-01 |
| [SOAR Cognitive Architecture](https://soar.eecs.umich.edu/) | Classic symbolic architecture with production rules and chunking; useful vocabulary for naming explicit control structures | 2025-07-01 |
| [ACT-R Cognitive Architecture](https://act-r.psy.cmu.edu/) | Classic modular cognition model with declarative/procedural memory distinction; useful when distinguishing memory types | 2025-07-01 |
| [CoALA Explained — Cognee Blog](https://www.cognee.ai/blog/fundamentals/cognitive-architectures-for-language-agents-explained) | Accessible explanation of how classical architectures map to LLM agent components | 2025-07-01 |
