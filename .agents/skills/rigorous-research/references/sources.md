# Sources

Canonical starting points for high-rigor research by source tier.

## Tier 1: Academic

- Google Scholar: `https://scholar.google.com/`
- Semantic Scholar: `https://www.semanticscholar.org/`
- PubMed: `https://pubmed.ncbi.nlm.nih.gov/`
- IEEE Xplore: `https://ieeexplore.ieee.org/`
- ACM Digital Library: `https://dl.acm.org/`
- arXiv: `https://arxiv.org/`

## Tier 2: Institutional and Official

- NIST: `https://www.nist.gov/`
- W3C: `https://www.w3.org/`
- IETF RFC Editor: `https://www.rfc-editor.org/`
- ISO: `https://www.iso.org/`
- ECMA International: `https://ecma-international.org/`
- MDN Web Docs: `https://developer.mozilla.org/`
- GitHub official docs: `https://docs.github.com/`
- WHO: `https://www.who.int/`
- OECD: `https://www.oecd.org/`
- World Bank: `https://www.worldbank.org/`

## Tier 3: Regulatory and Normative

- EUR-Lex: `https://eur-lex.europa.eu/`
- Congress.gov: `https://www.congress.gov/`
- legislation.gov.uk: `https://www.legislation.gov.uk/`
- Planalto: `https://www.planalto.gov.br/`
- Receita Federal: `https://www.gov.br/receitafederal/`

Use the original publisher whenever possible. If a source is mirrored, summarized, or quoted elsewhere, trace it back to the primary publication before citing it.
