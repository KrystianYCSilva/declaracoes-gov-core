# Sources

Authoritative references for quality assurance methodology, testing standards, and secure delivery.

## Testing Standards

- ISO/IEC/IEEE 29119 Software Testing standard (parts 1–5):
  `https://www.iso.org/standard/81291.html`
- ISO/IEC 25010 Software Product Quality (quality characteristics model):
  `https://www.iso.org/standard/35733.html`
- ISTQB Certified Tester Foundation Level syllabus:
  `https://www.istqb.org/certifications/certified-tester-foundation-level`
- ISTQB glossary of testing terms:
  `https://glossary.istqb.org/`

## Risk-Based Testing

- Risk-Based Testing (ISTQB Advanced Technical Test Analyst chapter):
  `https://www.istqb.org/certifications/advanced-level/technical-test-analyst`
- IEEE 1012 Software Verification and Validation:
  `https://standards.ieee.org/ieee/1012/6583/`

## Security and Secure SDLC

- OWASP Web Security Testing Guide (WSTG):
  `https://owasp.org/www-project-web-security-testing-guide/`
- OWASP Application Security Verification Standard (ASVS):
  `https://owasp.org/www-project-application-security-verification-standard/`
- NIST SP 800-64 Security Considerations in the System Development Life Cycle:
  `https://csrc.nist.gov/publications/detail/sp/800-64/rev-2/final`

## Operational Quality (SRE)

- Google SRE Book — Monitoring Distributed Systems:
  `https://sre.google/sre-book/monitoring-distributed-systems/`
- Google SRE Book — Release Engineering:
  `https://sre.google/sre-book/release-engineering/`
- Google SRE Workbook — SLOs:
  `https://sre.google/workbook/implementing-slos/`

## Usage Notes

- Use ISO 25010 when you need a vocabulary for quality attributes (reliability, security, usability, etc.).
- Use OWASP WSTG when testing for security vulnerabilities.
- Use the SRE book when operational resilience and release readiness overlap.
- These are reference standards; adapt them to the scale and risk profile of the actual delivery.
