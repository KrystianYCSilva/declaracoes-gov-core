# Sources

Official sources for Gemini CLI and adjacent standards.

- Gemini CLI home: `https://google-gemini.github.io/gemini-cli/`
- `GEMINI.md` project memory: `https://google-gemini.github.io/gemini-cli/docs/cli/gemini-md.html`
- Commands reference: `https://google-gemini.github.io/gemini-cli/docs/cli/commands.html`
- Configuration guide: `https://google-gemini.github.io/gemini-cli/docs/get-started/configuration.html`
- Custom commands: `https://google-gemini.github.io/gemini-cli/docs/cli/custom-commands.html`
- Headless mode: `https://google-gemini.github.io/gemini-cli/docs/cli/headless.html`
- Gemini CLI GitHub repository: `https://github.com/google-gemini/gemini-cli`
- Google Cloud Gemini CLI overview: `https://docs.cloud.google.com/gemini/docs/codeassist/gemini-cli`
- Google AI developer docs: `https://ai.google.dev/gemini-api/docs`
- Agent Skills specification: `https://agentskills.io/specification`

Use the Gemini CLI docs for runtime behavior and the Gemini API docs only for API-specific questions.
