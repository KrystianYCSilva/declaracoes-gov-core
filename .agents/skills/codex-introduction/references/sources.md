Key takeaways:

- Codex CLI is centered on interactive sessions, resume, and built-in slash commands.
- `/init` scaffolds `AGENTS.md`.
- Skills are the reusable workflow format.
- Plugins are the installable distribution unit for skills/apps.
- Codex has built-in subagents and supports custom TOML-based agents.
- The Open Agent Skills standard is the conceptual base for skills.
